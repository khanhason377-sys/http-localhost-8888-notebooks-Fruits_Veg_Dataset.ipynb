# Fruits and Vegetables Classification Using CNN

## 📌 Project Overview

This project focuses on classifying fruit and vegetable images using a **Convolutional Neural Network (CNN)** built with Python and deep learning techniques.

The model learns visual patterns from images and uses them to predict the category of an input image.

## 🎯 Project Objectives

- Build an image classification model using CNN.
- Learn how convolutional neural networks work for image recognition.
- Train a deep learning model on a fruits and vegetables image dataset.
- Predict the category of an image using the trained model.

## 🛠️ Technologies Used

- Python
- Jupyter Notebook
- TensorFlow / Keras
- NumPy
- Matplotlib
- CNN (Convolutional Neural Network)

## 🚀 How to Run the Project

2. Install the required libraries.
3. Download or place the dataset in the appropriate directory.
4. Open the project folder in VS Code or Jupyter Notebook.
5. Open `Fruits_Veg_Dataset.ipynb`.
6. Run the notebook cells in order.
7. Review the model training results and predictions.

## 🧠 How It Works

1. **Data Loading:** Load the fruits and vegetables image dataset.
2. **Preprocessing:** Prepare images for model training.
3. **CNN Model:** Build a convolutional neural network to learn image features.
4. **Model Training:** Train the model using the prepared image data.
5. **Prediction:** Use the trained model to classify input images.
6. **Evaluation:** Review the model's performance using the evaluation methods included in the notebook.
